## 3. The adversarial pass (§5, full)

- **A scale ArduPilot reads differently:** written as an exact quotient and judged as exact fractions.
  - 100 k / 9.09 k is `(109090.0f/9090.0f)`. A reduced equal quotient passes. `12.0011`, `12.00110011` and `12.0` are named.
  - A pin with an ADC3 channel alone is refused by hwdef, and named by the judge.
- **A judge that borrows the generator:** each expected value is computed from the topology alone:
  - the SWD expectation comes from pincheck's reset table;
  - the ODR from the topology;
  - the scale, pin and type from `power.sense` and `adc_inputs`.

  The two crates share no code (`separation.rs`).
- **PA13/PA14 solved to a net, or allow-listed:** refused in both crates, never overwritten.
- **`#define` spellings:**
  - `NAME (x)` and `NAME/**/(x)` are object-like (read as values, as GCC reads them);
  - `%:define NAME(x)` and a continuation before `(` are refused.
- **16 MHz against the 0 row, or the reverse:** a unit test drives SPI4 at 300 kHz: it passes at 0 Hz (floor 281,250 Hz) and is refused at 16 MHz (floor 390,625 Hz).
- **Mine:**
  - `HAL_BATT_VOLT_PIN` written in hex reads as C reads it.
  - A quotient with a zero denominator is no fraction.
  - Literals over 30 digits are refused before any multiply.
  - A chip select named `BATT_VOLTAGE_SENS` collides with the battery line's label (`LabelCollision`).
