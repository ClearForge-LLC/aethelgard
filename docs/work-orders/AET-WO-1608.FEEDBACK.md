- **`--out`.** Each case is tested:
  - a directory, a file (empty or not), a FIFO, a symlink (to a file, or dangling) and a missing directory are each refused, exit 3, and left as they were;
  - a FIFO is never opened, since `O_EXCL` fails first;
  - a path through a dangling directory link is refused and creates nothing;

## 7. Findings and rows for the architect

- **F1 (ruled a row):** a well-formed file is refused as `InvalidJson`, exit 3, when an externally tagged enum object is left `{}` (8 corpus mutants).
- **F2 (ruled a row):** `UnwitnessedAcknowledgementStale` could end with the ledger's own fields for that register and class, the most useful quote of all. Its text is in `cli/src/ledger.rs`.
- **F3:** a write that fails after the file is created (`ENOSPC`) leaves a partial file, and the message says so. It is never removed by path, since that could unlink a file another process put there. A partial file is not valid JSON, so `validate` refuses it (`InvalidJson`).
- **F4:** `LifecycleStatementInvalid` carries no `path`. A template holding a lifecycle statement could not make it a placeholder by path, which is why `sentinel-01-minimal` was not the template. It is a row only if a second template is wanted.
- **F5:** a second template, a board with power or serial, would need F4 and 30 or more acknowledgement placeholders. That is not proposed.
