- **F6 · My miss: the build-script rule, found by tier 1, not by me · stop, ruled (B) 22:29Z.**
  - `workspace_shape.rs` `no_member_has_a_build_script` has held since AET-WO-0100, whose §7 made "a `build.rs` that executes anything" a flag-and-stop. architecture §2 records why: a sandboxed `build.rs` on Furnace reached the D-Bus session and tmux's socket.

  - **(A) declined:** a single build script allowed by sha256 pin. Reason: a build script that runs `git` would run on every machine that runs `cargo install aethelgard-cli`, and a `--version` nicety is not worth reopening that hazard.
