## The headline, said plainly

**A1 is right, and the architect over-stated the P2 result.** P2's 47 kΩ failure is real ngspice arithmetic on a real netlist. But the netlist is built from two numbers the specification declares: the pull-up and `max_capacitance`, a bound used as if it were a measurement. The records call it "measured"; the architect repeated that to Scotty. Nothing physical about the routed board reaches the campaign yet.

The P2 gate stays passed, because its clauses were met as written. The record now says what the result is: a rise computed from declared values (`architecture.md` §2.15–§2.18 amended). Extraction is now scheduled before any fabrication package is called verified.
