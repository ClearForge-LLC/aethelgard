## The headline, said plainly

**The review is right, and the gap it names is the one that matters next.** The gates became honest about the board's copper. They are not yet honest about the silicon and the support circuitry. The reference board, as emitted and passed by every gate:
- cannot clock its SPI flash;
- gives the MCU one decoupling capacitor for 16 supply pins;
- cannot be programmed;
- declares a brown-out level nothing sets.

A1 would have failed in the first bench minute, and the bench sheet has been blank since the Nucleo arrived.

**A5 is the root cause**, and it is a weakness in how the architect specified the proof work orders. The Kani oracle was generated from the same calls as the code. "Pass criteria come from the specification" (`INV-07`) was met by the generator's reading of the specification, which is not independent. `motor::check_silicon` shows what independent means. `AET-WO-4230` applies it to every register family, and a witness ledger names what stays unwitnessed.

**On order:** the review asks for "a day of hardware truth before more surface". That is adopted in spirit:
- the three builders already running finish;
- the next builders launched are this response's four work orders, not new surface;
- `4400b`, `1303`'s build and `4500` wait behind them;
- the 3302 bench is the first thing on Scotty's hands-on list.

## New ruling

**`RUL-20`, independence of a judged fact.** A fact the generated firmware or board depends on counts as judged only when one of these holds:
- a rule in `aethelgard-ir` that shares no code with the generator decides it;
- the twin's model reacts to it;
- the bench measured it.

A check generated from the same calls as the code it checks is consistency, not judgement, and the `verify` verdict says so per field. This is how `INV-07` is read from now on.

## What the architect got wrong

- **Specifying proofs whose oracle came from the generator.** `4230` repairs it, and `RUL-20` prevents it.
- **Ruling "out of scope" without an owner.** The option byte (`4300d` D4) and DC bias (`4300d` D6) were each a fact that reached a gate. "Out of scope" is now a backlog row with an owner, or it is not written.
- **Letting `main` stay red for a day.** PR #150 was the fix; §6's line keeps it fixed.
- **Writing "P3's gate is past"** into the reviewer's brief while the bench clause is open.
