## 2. Taken

1. **Measure a dynamic campaign's archive volume before Sentinel-02's specification freezes.** The review's best catch. Architecture states "the dynamic case is estimated, not measured": 3 to 6 MB per simulated second at 10 µs quanta, against the reader's 256 MiB bound. A spike that gates `AET-WO-4500` (roadmap §5, §7.1).
2. **A binary-only path in the README:** install, validate and solve with no image, and what needs the image. Done in this PR.
3. **The generated board crate's `unsafe` contract, stated in `aethelgard-svd-hal`'s README.** Done in this PR.
4. **A CI snapshot of the MCP tool list,** so a changed tool contract cannot pass unseen. `mcp.rs` computes the list from the command tree, and nothing compares it to a committed copy. Backlog: the next CLI work order.
5. **`aethelgard doctor`:** the binary's version, the Landlock ABI and seccomp, the tools present, and the scratch's ownership, so exit 4 can be explained without reading `run.rs`. Backlog: the next CLI work order.

## 3. Taken with a change, or ruled

- **`aethelgard migrate` that fills documented defaults: not taken.** It breaks `INV-06` (nothing substitutes a default). The `INV-06`-safe half is taken: given an older file, `validate` refuses with the **complete** list of fields the current version requires, each with the version and work order that added it. Today it names only the first. Backlog: the next validation work order.
- **A schema epoch: agreed, not yet (Scotty, 2026-11-17).** Once `AET-WO-4500` settles Sentinel-02's specification shape, that version is named the P4 baseline, and later additions are additive rather than renumbered. Not now, because too much is in flight (`1312` takes 14; `4400b` takes the next solved and parts schemas). The trigger is written into `4500`'s roadmap entry.
- **A "silicon-observed" mode in the judge** that fails firmware matching a known twin-versus-silicon disagreement: **deferred to the bench.** The first scar's cause was fixed at source (`4230`: the firmware writes `SSM` and `SSI` before `SPE`). A pattern needs more than one instance. Sentinel-01's bench rows (`3401` `BENCH.md`) are where the next ones will come from.
- **The licence note at the point of use** (the generated project's README): **backlog, low.** The obligation is none, and the kicad-lib README says so at `crates/aethelgard-kicad-lib/README.md:7`.
- **`examples/UPGRADE.md`:** folded into the complete-list refusal above, which answers the same question from the tool.
