# KiCad 10.0.7 library items, vendored

The few symbols and footprints `aethelgard-eda` emits, copied byte for byte from KiCad's own libraries at tag **10.0.7**. This is the KiCad version in the tools image (`container/IMAGE`). The ruling is D1 on PR #40 (`docs/work-orders/AET-WO-1300.FEEDBACK.md`).

- **Symbols:** from `https://gitlab.com/kicad/libraries/kicad-symbols`. At 10.0.7 each library is a `<Lib>.kicad_symdir/` directory with one file per symbol; each file is vendored whole, unmodified.
- **Footprints:** from `https://gitlab.com/kicad/libraries/kicad-footprints`, one `.kicad_mod` file each.

**Licence:** these files are licensed CC-BY-SA 4.0, with KiCad's design exception; the text is in `LICENSE.md`, beside them. That exception covers the designs and generated files made from them, so the emitted schematics and boards carry no obligation from it (`RUL-11`). The files themselves, redistributed here, stay under CC-BY-SA 4.0. Hence `aethelgard-eda`'s licence, `(MIT OR Apache-2.0) AND CC-BY-SA-4.0`.

**Integrity:** `src/library.rs` holds each file's sha256 and checks every one before any is used, as `aethelgard-svd-hal` does for ST's data. A mismatch is a corrupted build. Each file's git blob SHA below is what GitLab's files API reports at ref 10.0.7, and it matches the blob SHA of the bytes here.
