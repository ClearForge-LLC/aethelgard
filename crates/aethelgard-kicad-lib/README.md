# aethelgard-kicad-lib

KiCad 10.0.7's symbols, footprints and licence text that Aethelgard vendors, as one table of bytes (`FILES`). It holds data only: no hashes, no parsing, no dependencies. `aethelgard-eda` pins each file's sha256 and refuses a file that is missing, unpinned or altered.

**Licence:** CC-BY-SA 4.0, with KiCad's design exception. The libraries' own licence text sits beside them in `data/kicad-10.0.7/LICENSE.md`.

**Designs emitted from it carry no obligation.** Schematics and boards built from these files fall under KiCad's design exception (`RUL-11`).
