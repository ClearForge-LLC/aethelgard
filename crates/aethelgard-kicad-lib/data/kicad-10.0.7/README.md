# KiCad 10.0.7 library items, vendored

The few symbols and footprints `aethelgard-eda` emits (the JST GH and SH connectors and their mounting-pin symbols added by `AET-WO-4300f`, ruled D3 and D4 on PR #134; the power tree's parts added by `AET-WO-4300d2`, ruled D11 and D12 of `AET-WO-4300d`: the LMR33630 buck, the TLV75518P and TLV70012 regulators, the TXU0304 level translator, an inductor, the XT30PW-M connector and the 0603 and 1210 passives; and the ICM-20948, vendored so the power fixture's 1.8 V IMU, behind the TXU0304 crossing, can be drawn), copied byte for byte from KiCad's own libraries at tag **10.0.7**. This is the KiCad version in the tools image (`container/IMAGE`). The ruling is D1 on PR #40 (`docs/work-orders/AET-WO-1300.FEEDBACK.md`).

- **Symbols:** from `https://gitlab.com/kicad/libraries/kicad-symbols`. At 10.0.7 each library is a `<Lib>.kicad_symdir/` directory with one file per symbol; each file is vendored whole, unmodified.
- **Footprints:** from `https://gitlab.com/kicad/libraries/kicad-footprints`, one `.kicad_mod` file each.

**Licence:** these files are licensed CC-BY-SA 4.0, with KiCad's design exception; the text is in `LICENSE.md`, beside them. That exception covers the designs and generated files made from them, so the emitted schematics and boards carry no obligation from it (`RUL-11`). The files themselves, redistributed here, stay under CC-BY-SA 4.0. Hence `aethelgard-eda`'s licence, `(MIT OR Apache-2.0) AND CC-BY-SA-4.0`.

**Integrity:** `src/library.rs` holds each file's sha256 and checks every one before any is used, as `aethelgard-svd-hal` does for ST's data. A mismatch is a corrupted build.
