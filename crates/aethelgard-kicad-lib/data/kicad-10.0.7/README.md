# KiCad 10.0.7 library items, vendored

The few symbols and footprints `aethelgard-eda` emits (the JST GH and SH connectors and their mounting-pin symbols added by `AET-WO-4300f`, ruled D3 and D4 on PR #134; the power tree's parts added by `AET-WO-4300d2`, ruled D11 and D12 of `AET-WO-4300d`: the LMR33630 buck (and `AET-WO-4411`'s LMR33620, which extends the same `LMR33640ADDA`), the TLV75518P and TLV70012 regulators, the TXU0304 level translator, an inductor, the XT30PW-M connector and the 0603 and 1210 passives; the ICM-20948, vendored so the power fixture's 1.8 V IMU, behind the TXU0304 crossing, can be drawn; and `AET-WO-1312`'s test point and reset switch: KiCad's `Connector:TestPoint` and `Switch:SW_Push` symbols, the `TestPoint_Pad_D1.0mm` pad and C&K's `SW_SPST_PTS810` footprint; and `AET-WO-4240c`'s crystal: `Device:Crystal_GND24` and `Crystal:Crystal_SMD_3225-4Pin_3.2x2.5mm`, named by `4240a` D-4; and `AET-WO-1211d`'s DRV8833 footprint, PWP0016C without thermal vias, `HTSSOP-16-1EP_4.4x5mm_P0.65mm_EP3.4x5mm_Mask2.46x2.31mm`, which cites the DRV8833 datasheet's own land pattern; its symbol is our own, `../aethelgard/`; and `AET-WO-4300k`'s Sentinel-03 parts: `Device:D_Zener` and `Diode_SMD:D_SOD-123` for the MMSZ5242B, `Device:Fuse` and `Fuse:Fuse_1206_3216Metric` for the Bourns SF-1206F, `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm` for the DMP6023LSS and `Package_TO_SOT_SMD:SOT-23-3` for the TLV803S; their symbols are our own where KiCad has none, `../aethelgard/`; and `AET-WO-4411`'s radio module symbol: KiCad's `RF_Module:ESP32-C3-WROOM-02`, whose footprint is our own, derived from KiCad's, `../aethelgard/`), copied byte for byte from KiCad's own libraries at tag **10.0.7**. This is the KiCad version in the tools image (`container/IMAGE`). The ruling is D1 on PR #40 (`docs/work-orders/AET-WO-1300.FEEDBACK.md`).

- **Symbols:** from `https://gitlab.com/kicad/libraries/kicad-symbols`. At 10.0.7 each library is a `<Lib>.kicad_symdir/` directory with one file per symbol; each file is vendored whole, unmodified.
- **Footprints:** from `https://gitlab.com/kicad/libraries/kicad-footprints`, one `.kicad_mod` file each.
