# Aethelgard's own symbols and footprints

**Licence: `MIT OR Apache-2.0`,** the same terms as the engine (`RUL-11`; the texts are `LICENSE-MIT` and `LICENSE-APACHE` at the repository root). These files are our own work, authored from the makers' datasheets for parts KiCad 10.0.7's libraries do not carry (`AET-WO-4220` D5, ruled on PR #140). **One file is the exception:** `footprints/Aethelgard_RF.pretty/ESP32-C3-WROOM-02.kicad_mod` is derived from KiCad's, so ITS licence is `CC-BY-SA-4.0` with KiCad's design exception (text: `../kicad-10.0.7/LICENSE.md`), not `MIT OR Apache-2.0` (`AET-WO-4411` D4). The vendored KiCad files beside them, under `../kicad-10.0.7/`, keep their own CC-BY-SA 4.0 licence. Designs emitted from either carry no obligation from this project.

Each file was written from the cited pages, then re-saved by KiCad 10.0.7's own `kicad-cli fp upgrade --force` or `kicad-cli sym upgrade --force`, so that its bytes are KiCad's canonical form. `aethelgard-eda` pins every file's sha256 and checks each pad and pin against its citation table, which it holds apart from these files (`AET-WO-4220b`).

Each sensor footprint carries two keepout zones: on `F.Cu`, the area inside its ring of pads (no track, via or copper pour); on `B.Cu`, the body at its maximum outline (no track or via).

The DRV8876's footprint carries none: SLVSDS7B §10.1 (p. 32) asks for the thermal pad to be joined to the ground plane, not for a keepout. Its exposed pad is three pads, as KiCad draws a PowerPAD: pad `17` on `F.Cu` alone (3.4 × 5), and two unnumbered pads, one on `F.Mask` and one on `F.Paste` (each 3.3 × 3.3).
